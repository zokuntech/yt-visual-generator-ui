# 🎬 YouTube Shorts Generator - Export Workflow

**Generate viral transformation content WITHOUT built-in video generation**

## 🎯 What This Feature Does

The Shorts Generator creates **6 keyframe images + 5 detailed text prompts** for external video generation tools. It does NOT generate videos directly - instead, it provides everything you need to create professional timelapses in Runway, Pika, Kling, or any image-to-video tool.

### Why This Approach?

- ✅ **Much cheaper** - ~$0.10-0.15 vs ~$0.70-1.00 per short
- ✅ **More flexibility** - Use your preferred video tool
- ✅ **Better control** - Fine-tune motion and timing externally
- ✅ **Faster iteration** - Regenerate images quickly without video wait times
- ✅ **MORE PEOPLE** - Stages 2, 3, 4 feature 2-4 workers for engaging content 👷‍♀️👷👷‍♂️
- ✅ **Visual consistency** - Same camera angle, room layout, lighting across all 6 stages

## 📦 What You Get

For each Short project, you receive:

### 1. Six Keyframe Images

**Stage 1: Empty/Before** (2-3 seconds)
- Raw, unfinished state
- Bare concrete, exposed walls, construction debris
- NO workers, NO people
- Sets the "before" context

**Stage 2: Prep Work** (3-4 seconds) 👷
- **2-3 workers preparing** in safety gear
- Grinding, measuring, marking surface
- Prep equipment visible (grinders, vacuums, tape)
- Focused, organized energy

**Stage 3: Active Installation** (5-6 seconds) 👷‍♀️👷👷‍♂️ **[HERO SHOT!]**
- **3-4 workers collaborating** on main work
- Most dynamic and energetic scene
- Main transformation moment (e.g., pouring epoxy)
- Tools in use, materials being applied

**Stage 4: Finishing Touches** (3-4 seconds) 👷
- **2-3 workers doing detail work**
- Quality checking, smoothing, perfecting
- Workers cleaning up equipment
- Calmer but focused atmosphere

**Stage 5: Completed Empty** (3-4 seconds)
- Main transformation complete
- Finished product, pristine
- Maybe 1 worker admiring or completely empty
- NO furniture yet

**Stage 6: Fully Furnished** (3-4 seconds)
- Final styled version
- Furniture, decor, lived-in feel
- Complete transformation, "after" reveal

**Total Duration**: ~20-25 seconds (perfect for Shorts!)
**Total People**: 7-10 workers across stages 2, 3, 4

Each image is:
- **9:16 aspect ratio** (vertical for Shorts) or 16:9 (landscape)
- **High quality** PNG format (data URI)
- **Downloadable** individually or all at once
- **Editable** with AI-assisted text instructions
- **Visually consistent** - same camera angle, room layout, lighting

### 2. Five Transition Prompts

- **Transition 1**: Stage 1 → Stage 2 (5-7 seconds) - Workers entering with equipment
- **Transition 2**: Stage 2 → Stage 3 (7-9 seconds) - Main work beginning
- **Transition 3**: Stage 3 → Stage 4 (8-10 seconds) - **[HERO TRANSITION]** Main installation completing
- **Transition 4**: Stage 4 → Stage 5 (6-8 seconds) - Final touches, workers exiting
- **Transition 5**: Stage 5 → Stage 6 (5-7 seconds) - Furniture appearing, final reveal

Each prompt is:
- **150-300 words** of detailed motion description
- **Optimized for AI video tools** (Runway, Pika, Kling)
- **Copy-to-clipboard** ready
- **Camera-aware** (static angle for authentic timelapse)
- **Continuity markers** - explicitly mentions what stays the same (camera, room, lighting)

### 3. JSON Export

Complete project data including:
- All 6 images (as data URIs)
- All 5 transition prompts
- Metadata (duration, workers count, stage types, cost)
- Ready to import into external tools

## 🎨 Visual Consistency - The "Room Anchor"

Every project establishes a "room anchor" that remains constant across all 6 stages:

### What Stays the Same ✅
- **Camera Position**: e.g., "wide angle from doorway, eye-level, capturing entire room"
- **Room Layout**: e.g., "20x15 foot rectangular space, window left wall, exposed brick right"
- **Lighting Setup**: e.g., "natural daylight from left window, overhead construction lights"
- **Architectural Features**: Windows, doors, walls, ceiling details

### What Changes 🔄
- People entering, working, leaving (stages 2, 3, 4)
- Materials and tools appearing and being used
- Floor/product progressing from raw to finished
- Debris accumulating and being cleaned up
- Furniture appearing in final stage

This ensures all 6 images look like a **true timelapse** from the same camera!

## 🎥 Using Your Export with Video Tools

### Recommended Tools

**Image-to-Video (Frame Interpolation):**
- **Runway Gen-3** - Best quality, upload 2 keyframes + prompt
- **Pika Labs** - Great motion control, good for construction content
- **Kling AI** - Excellent for timelapse and transformation videos
- **Luma AI** - Smooth transitions, good consistency

### Workflow with Runway Gen-3

1. **Export from Shorts Generator**
   - Download all 6 images
   - Copy all 5 transition prompts

2. **Create Transition 1** (Empty → Prep)
   - Upload Stage 1 image as start frame
   - Upload Stage 2 image as end frame
   - Paste transition 1 prompt
   - Set duration: 5-7 seconds
   - Generate video

3. **Create Transition 2** (Prep → Installation)
   - Upload Stage 2 as start
   - Upload Stage 3 as end
   - Paste transition 2 prompt
   - Duration: 7-9 seconds
   - Generate video

4. **Create Transition 3** (Installation → Finishing) **[HERO TRANSITION]**
   - Upload Stage 3 as start
   - Upload Stage 4 as end
   - Paste transition 3 prompt
   - Duration: 8-10 seconds
   - Generate video

5. **Create Transition 4** (Finishing → Complete)
   - Upload Stage 4 as start
   - Upload Stage 5 as end
   - Paste transition 4 prompt
   - Duration: 6-8 seconds
   - Generate video

6. **Create Transition 5** (Complete → Furnished)
   - Upload Stage 5 as start
   - Upload Stage 6 as end
   - Paste transition 5 prompt
   - Duration: 5-7 seconds
   - Generate video

7. **Stitch Together**
   - Combine all 5 videos in your editor
   - Add music/sound effects
   - Total length: ~20-25 seconds

### Tips for Best Results

- **Use Keyframes**: Upload start and end images as keyframes (most tools support this)
- **Static Camera**: All prompts already specify "static camera, no movement"
- **Duration**: Use the suggested durations in each transition
- **Aspect Ratio**: Use the same ratio as your images (9:16 or 16:9)
- **Same Tool**: Generate all 5 transitions with the same tool/settings for consistency
- **Reference Markers**: The prompts mention specific features (windows, walls) to help maintain continuity
- **People Motion**: Transitions 1-4 include worker movement - make sure your tool supports this

## ✏️ Editing Stage Images

Don't like how a stage turned out? You can refine it:

### Option 1: Regenerate (Same Prompt)
- Click "Regenerate" button on any stage
- Gets a fresh variation without changing anything
- Useful for trying different compositions or worker positions
- **Cost**: ~$0.01

### Option 2: Edit with Instruction
- Click "Edit" button on any stage
- Opens modal with AI suggestions
- Type what you want to change
- Use "Make More Specific" to refine vague instructions
- **Cost**: ~$0.01

### AI Edit Suggestions

The edit modal provides category-specific suggestions:

**For Stage 1 (Empty Room):**
- Add more construction debris
- Adjust lighting (darker, more dramatic)
- Change atmosphere (dustier, more industrial)

**For Stage 2 (Prep Work - 2-3 workers):**
- Add or remove workers
- Change what workers are doing (grinding, measuring, marking)
- Add more prep equipment

**For Stage 3 (Active Installation - 3-4 workers) [HERO SHOT]:**
- Adjust number of workers (should be 3-4)
- Change worker positions and actions
- Modify main installation activity (e.g., "make epoxy pour more dramatic")

**For Stage 4 (Finishing Touches - 2-3 workers):**
- Adjust detail work being performed
- Add or remove cleanup equipment
- Change worker focus (quality checking, smoothing, etc.)

**For Stage 5 (Completed Empty):**
- Adjust finish quality and reflections
- Change lighting to highlight work
- Modify colors or textures

**For Stage 6 (Fully Furnished):**
- Add/remove furniture
- Change style (modern, rustic, industrial)
- Adjust lighting for ambiance

### Example Edit Instructions

```
Stage 2: "add more workers (need 3 people), show them using grinders and vacuums"
Stage 3: "make epoxy pour more dramatic, show all 4 workers actively working together"
Stage 4: "show 2 workers cleaning equipment and doing final smoothing"
```

## 🔧 Troubleshooting

### Not enough people in stages 2-4
**Problem**: Stages 2, 3, and 4 should have 2-4 workers visible
**Expected**:
- Stage 2: 2-3 workers
- Stage 3: 3-4 workers (most people)
- Stage 4: 2-3 workers

**Solution**: 
- If workers aren't appearing, try regenerating the specific stage
- Or use "Edit" to manually add workers: "add 3 workers in safety gear actively working"

### Images don't look consistent (different angles/rooms)
**Problem**: The 6 stages don't look like they're from the same room

**Solution**: 
1. Regenerate the entire project (sometimes the AI needs another try)
2. If issue persists, check the stage prompts - they should all reference the same "camera position" and "room features"
3. Use the edit feature to fix specific stages: "match the camera angle and room layout from stage 1"

**Best Practice**: When exporting, review all 6 images side-by-side. They should look like frames from a timelapse video of the same space.

### Transition videos don't match the images
**Problem**: The video tool generates transitions that don't match

**Solution**:
1. Make sure you're uploading both start AND end images as keyframes
2. Use "image-to-image" or "frame interpolation" mode (not text-to-video)
3. Include the full transition prompt - don't truncate it
4. The prompts include continuity markers - make sure your tool respects these
5. Try a different tool - Runway Gen-3 and Kling AI are best for consistency

### Export not working
- Ensure all 6 images are fully generated (`image_status: "generated"`)
- Check browser console for errors
- Try downloading images individually first
